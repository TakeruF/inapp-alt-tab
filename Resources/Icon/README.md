# App icon

`AppIcon.png` is the generated master. `../AppIcon.icns` contains the standard macOS sizes and is bundled by `scripts/build-app.sh`. Regenerate the ICNS after updating the master with:

```sh
bash scripts/build-icon.sh
```

Created with the built-in imagegen tool. Final prompt:

> Use case: logo-brand. Asset type: production macOS application icon for InApp Alt Tab, a utility that instantly cycles windows of the current application. Create one polished 1024x1024 icon, a large macOS rounded-square tile centered with transparent margins. Deep cobalt/indigo tile with subtle luminous blue gradient and restrained dimensional depth. Inside, two overlapping bright rounded rectangular application windows, clean thin top bars, paired curved switching arrows or one clear sweeping arrow linking them. Simple and bold legible silhouette at 32px, modern native macOS utility aesthetic, balanced central composition. No text, no letters, no keyboard keys, no logo brands, no surrounding scene, no mockup, no watermark. Transparent outside the rounded tile. Finished icon only.
